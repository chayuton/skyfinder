# ดาวนำทาง — Sky Finder

แอปดูดาวภาษาไทย ใช้พิกัดของเครื่องคำนวณตำแหน่งดวงอาทิตย์ ดวงจันทร์ ดาวเคราะห์
และดาวฤกษ์ 240 ดวงแบบเรียลไทม์ พร้อมผังกลุ่มดาว 40 กลุ่มที่วาดตามมุมเอียงจริงบนฟ้า

Flutter · Dart · ออกได้ทั้ง Android, iOS, Web, Windows, macOS, Linux จากโค้ดชุดเดียว

---

## ⚠️ อ่านก่อนใช้งาน

**โค้ดชุดนี้ยังไม่เคยถูกคอมไพล์** สภาพแวดล้อมที่สร้างมันไม่มี Flutter SDK
และเข้าถึง pub.dev ไม่ได้ จึงรัน `flutter analyze` หรือ `flutter build` ไม่ได้เลย

สิ่งที่ตรวจแล้ว:

* โครงสร้างไฟล์ทั้ง 18 ไฟล์ — วงเล็บครบ สตริงปิดครบ import ชี้ไปยังไฟล์ที่มีจริง
* ชื่อฟังก์ชันระดับบนสุดทุกตัวที่ถูกเรียก มีนิยามอยู่จริง
* **ข้อมูลดาวและสถานที่ตรงกับต้นฉบับทุกค่า** — เทียบ 240 ดาว (id, RA, Dec, โชติมาตร)
  และ 77 จังหวัด (พิกัด ความสูง) กับชุดข้อมูลที่ผ่านการตรวจสอบมาแล้ว ไม่มีค่าใดเพี้ยน
* กับดักเฉพาะของ Flutter ที่รู้ว่าจะพังได้ ถูกเลี่ยงไว้แล้ว (ดูหัวข้อถัดไป)

สิ่งที่ยังไม่ได้ตรวจ: ชนิดข้อมูล, API ของปลั๊กอิน, การจัดวางวิดเจ็ต, การเรนเดอร์จริง

**ขั้นตอนแรกที่ควรทำคือรันเทสต์** ซึ่งจะบอกทันทีว่าคณิตศาสตร์ถูกต้องหรือไม่

## เริ่มใช้งาน

```bash
flutter create --org th.skyfinder --project-name skyfinder .
flutter pub get
flutter test          # ← ทำข้อนี้ก่อน
```

`flutter create .` จะเติมโฟลเดอร์ `android/`, `ios/`, `web/` ให้ โดยไม่แตะ `lib/`
`test/` `pubspec.yaml` ที่มีอยู่แล้ว

จากนั้นเติมสิทธิ์ตาม `PERMISSIONS.md` (จำเป็น ไม่งั้น GPS และเข็มทิศจะไม่ทำงาน) แล้ว

```bash
flutter run                      # ลงเครื่องที่เสียบสาย
flutter build apk --release      # ได้ไฟล์ .apk
flutter build ipa                # ต้องใช้ Mac + Xcode
flutter build web                # ได้เว็บแอป ขึ้น Vercel/GitHub Pages ได้
```

### ชุดทดสอบบอกอะไร

`test/engine_test.dart` มี 209 assertion แบ่งเป็นสี่กลุ่ม:

1. **ตัวอย่างอ้างอิงของ Meeus** — ดวงจันทร์ตัวอย่าง 47.a และดวงอาทิตย์ 25.b
   ซึ่งเป็นค่ามาตรฐานที่ตำราดาราศาสตร์ใช้ตรวจสอบโปรแกรม
2. **การแปลงพิกัดและค่าคงที่** — ใจกลางทางช้างเผือก ขอบฟ้ากดลง ชื่อทิศ
3. **มุมเอียงผังกลุ่มดาว** — ต้องเท่ากับมุมพารัลแลกติกเชิงทฤษฎี
   ถ้าเครื่องหมายกลับด้าน ผังทุกกลุ่มจะเป็นภาพกระจก ซึ่งแย่กว่าไม่มีผังเลย
4. **ค่าจริง 5 สถานที่** — กรุงเทพฯ เชียงใหม่ ดอยอินทนนท์ เกาะหลีเป๊ะ หนองคาย
   เทียบตำแหน่งวัตถุทั้ง 9 ดวง เวลาขึ้น-ตก และแสงสนธยา กับค่าที่คำนวณจาก
   เวอร์ชันที่ผ่านการตรวจสอบแล้ว ความคลาดเคลื่อนที่ยอมรับได้คือ 1e-6 องศา

**ถ้าเทสต์ผ่าน แปลว่าการพอร์ตคณิตศาสตร์ถูกต้อง** ถ้าไม่ผ่าน ตัวเลขในแอปจะผิด
และชื่อเทสต์จะบอกว่าพังตรงไหน

## จุดที่ควรดูก่อนถ้าคอมไพล์ไม่ผ่าน

ผมเลี่ยงกับดักที่รู้ไว้แล้ว แต่เพราะคอมไพล์ไม่ได้ สามจุดนี้น่าสงสัยที่สุด:

| จุด | เหตุผล | ถ้าพัง |
|---|---|---|
| `sensors_plus` | ใช้ `accelerometerEventStream()` และ `magnetometerEventStream()` ซึ่งเป็น API ของเวอร์ชัน 4 ขึ้นไป รุ่นเก่าใช้ `accelerometerEvents` แบบ getter | แก้สองบรรทัดใน `lib/state/app_state.dart` |
| `geolocator` | `getCurrentPosition` เปลี่ยนพารามิเตอร์เป็น `locationSettings` ในเวอร์ชัน 13 รุ่นก่อนหน้าใช้ `desiredAccuracy` กับ `timeLimit` ตรง ๆ | แก้ใน `requestLocation()` ไฟล์เดียวกัน |
| `withOpacity` | เลือกใช้แทน `withValues` เพราะคอมไพล์ได้ทุกเวอร์ชัน จะมีคำเตือน deprecated ซึ่งปิดไว้ใน `analysis_options.yaml` แล้ว | ถ้าถูกถอดออกจริงในอนาคต ให้แทนด้วย `withValues(alpha:)` |

สิ่งที่ **ไม่ต้องห่วง** คือ `lib/engine/` กับ `lib/data/` เพราะเป็น Dart ล้วน
ไม่พึ่งปลั๊กอินใด และมีเทสต์คุมอยู่

## โครงสร้าง

```
lib/
  data/
    stars.dart        240 ดาว 40 กลุ่ม 223 เส้น 12 วัตถุห้วงลึก 10 ฝนดาวตก
    places.dart       77 จังหวัด + หอดูดาว NARIT และเขตอนุรักษ์ท้องฟ้ามืด 25 แห่ง
  engine/
    engine.dart       คณิตศาสตร์ดาราศาสตร์ทั้งหมด ไม่ import Flutter เลย
    sky.dart          ประกอบฉาก ปฏิทินรายคืน และคำตัดสินที่ UI ต้องใช้
  painters/           CustomPainter: โดมฟ้า โหมดเล็ง ผังกลุ่มดาว ข้างขึ้นข้างแรม
  state/app_state.dart  ChangeNotifier เดียวคุมทุกอย่าง รวมการรวมค่าเซ็นเซอร์
  ui/                 6 แท็บ ชีต เข็มทิศ และธีม
test/engine_test.dart
```

`engine.dart` ไม่ import Flutter เลย จึงรันด้วย `dart test` เดี่ยว ๆ ได้
และเอาไปใช้ในโปรเจกต์อื่นได้ทันที

### เรื่องเซ็นเซอร์

แอปไม่พึ่ง stream ที่ให้ค่ามุมมาสำเร็จรูป แต่อ่าน **ความเร่งกับสนามแม่เหล็ก**
ซึ่งเป็นเซ็นเซอร์ที่มือถือทุกเครื่องมี แล้วสร้างเมทริกซ์การหมุนเอง
(H = m × a คือทิศตะวันออก, M = a × H คือทิศเหนือ, a คือทิศขึ้น)
วิธีนี้ตรงกับที่ `SensorManager.getRotationMatrix` ของ Android ทำ

จุดละเอียดที่ซ่อนอยู่: ตอนถือมือถือแบนราบ กล้องหลังชี้ลงพื้น ค่าทิศจากแกนนั้นจะสะบัด
โค้ดจึงเลือกอ่านจากขอบบนของเครื่องแทนเมื่อถือแบน และกลับไปอ่านจากกล้องหลังเมื่อยกขึ้นฟ้า

## ความแม่นยำ

* ดวงจันทร์ (ELP2000 ฉบับย่อ) ตรงกับตัวอย่าง 47.a ของ Meeus ถึงทศนิยมที่ 6
* ดวงอาทิตย์ ตรงกับตัวอย่าง 25.b คลาด 1e-5 องศา
* ดาวเคราะห์ ใช้ธาตุวงโคจรโดยประมาณของ JPL แม่นระดับลิปดาในช่วงปี 1800–2050
* ดวงจันทร์แก้ค่าพารัลแลกซ์ตามตำแหน่งผู้สังเกต ซึ่งคลาดได้ถึง 1 องศาถ้าไม่แก้
  (กว้างเท่าดวงจันทร์สองดวงเรียงกัน)
* มุมเงยรวมการหักเหของบรรยากาศ และขอบฟ้ากดลงตามความสูงของจุดสังเกต
  ที่ยอดดอยอินทนนท์ขอบฟ้ากดลง 1.48 องศา ทำให้ดวงอาทิตย์ตกช้ากว่าในเมืองราว 6 นาที
* ตำแหน่งดาวฤกษ์เลื่อนตามการหมุนควงของแกนโลกถึงวันที่ปัจจุบัน

## ข้อจำกัดของข้อมูลสถานที่

NARIT และ ททท. ประกาศเขตอนุรักษ์ท้องฟ้ามืดรวมกว่า 79 แห่ง แต่**ไม่มีหน่วยงานใด
เผยแพร่พิกัดตัวเลขรายแห่ง** ในแอปจึงใส่เฉพาะแห่งที่หาพิกัดจากแหล่งอ้างอิงได้
และกำกับว่า "ค่าประมาณระดับพื้นที่" กับแห่งที่ยังไม่ยืนยัน
คลาดสัก 1–2 กม. ไม่มีผลต่อการคำนวณดาว แต่มีผลตอนขับรถไปหา

ทะเบียนเขตท้องฟ้ามืดมีอายุ 3 ปี รายชื่อจากปี 2565 บางแห่งอาจหมดสถานะแล้ว
